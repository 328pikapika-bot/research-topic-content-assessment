# 科研选题与内容评估平台

[English](README.en.md) | 简体中文

面向科研人员和科研项目管理人员的智能体工作台，包含智能选题、内容评估两条业务线。

## 主要功能

- 智能选题：从研究方向形成检索计划、研究空白和候选问题。
- 内容评估：整理论文或项目材料中的主张与指标，以文献证据形成分析和报告。
- 提供任务创建、进度、历史记录、文件处理与结果展示；两类任务各自管理状态和报告。

## 源码与运行入口

`源码/backend/` Python API 与智能体；`源码/frontend/web/` Vue 前端；`源码/database/` 数据初始化；`源码/docker/` 部署示例；`源码/tests/` 测试。

Python 3.11、Node.js 20、MongoDB，以及自有模型、文献检索、全文和敏感检测服务。Python 依赖以 `源码/pyproject.toml` 为准，前端依赖以 `源码/frontend/web/package.json` 为准。

后端入口 `源码/backend/app/main.py`，前端入口 `源码/frontend/web/`。`源码/docker/compose.local.yml` 提供本机 Compose 示例，填写环境变量后再使用。

## 配置

模型 Key、MongoDB 口令和检索/全文/敏感检测地址通过环境变量配置。`VITE_NSTL_DEMO_PASSWORD` 只用于前端演示入口，会进入前端构建产物，不能作为正式鉴权。

配置示例位于源码中的 `.env.example`。真实凭证只保存在本机环境或不跟踪的 `.env` 中。`127.0.0.1` 与 `example.invalid` 为本地/不可解析示例地址，部署前替换为自己的配置。

## 验证与边界

研究方案智能体属于历史规划，当前不作为第三条已验证业务线。真实任务回放夹具和报告已排除，部分历史 QA 回放需自行准备数据；模型、检索和生产部署未联通验证。
